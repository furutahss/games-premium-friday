# 15:00 退社チャレンジ

プレミアムフライデーにちなんだ、React + TypeScript + Vite のブラウザゲーム。
会議・差し戻し・至急案件をかわし、45秒生存して15時退社を目指します。

## 起動

```sh
npm install
npm run dev
```

http://localhost:5175/premium-friday/ を開いてください。

## 操作とルール

- 左右矢印 / A・Dキー、画面下のボタン、左右スワイプでレーンを移動
- Space / Esc または一時停止ボタンで一時停止・再開
- タブ移動・ウィンドウのフォーカスが外れた場合は自動で一時停止
- 案件に3回当たるとゲームオーバー。被弾後1.4秒は無敵
- 案件回避 +30pt、生存1秒 +20pt
- アイテム：コーヒー150pt（62%）、ドーナツ300pt（25%）、週末切符700pt（10%）、有休届1,500pt（3%）。割合はアイテム出現時の内訳
- アイテム連続回収で倍率アップ：1〜3個目×1、4〜6個目×2、7〜9個目×3、10〜12個目×4、13個目以降×5。取り逃し・案件への接触でコンボリセット
- 各案件の列で72%の確率で空きレーンにアイテムが出現。12秒以降は2レーンをふさぐ案件も発生。終盤に向けて速度と出現頻度が上昇
- クリア時に残り気力 ×200pt。ベストスコアはブラウザ内に保存（新版ルールで別記録。旧ルールの保存データは保持）

## 検証とビルド

```sh
npm test
npm run build
npm run preview
```

`dist/` の内容を `https://games.furutahss.com/premium-friday/` に配置します。
Viteの `base` は `/premium-friday/` に設定済み。ページ内ルーティングは使用していないため、SPAフォールバック設定は不要です。
Google Fontsを利用しています。読み込めない場合は端末の標準フォントで動作します。
